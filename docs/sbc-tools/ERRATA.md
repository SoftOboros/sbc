## Entry procedure

Use ADDENDUM-B's status vocabulary, boundary rules, and permanent entry shape.
An entry records symptom, root cause, proposed fix, verification, and tracking.
Resolution requires recorded repair evidence; an approved exception must not
be presented as verified repair. Preserve prior entries and evidence. Changes
to normative phase content use the owning phase's §15 record, referenced from
the erratum. No errata have been closed or waived by opening this family.
